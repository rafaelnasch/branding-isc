Antes de colar

Quatro regras antes de qualquer código.

Valem para os treze blocos. O resto está no comentário que abre cada código.

A marca é arquivo

Sempre um arquivo de assets/ ou o data URI deste manual. Nunca redesenhe, redigite o ISC em fonte, recolora, gire, estique ou aplique sombra ou brilho.

A versão segue o fundo

Ouro metálico sobre Preto ISC ou Noite. Preta sobre marfim, branco ou areia. Branca sobre foto escura com sombra de leitura. Ouro nunca vai para o claro.

Respiro de x

x é o dobro do diâmetro de um ponto do símbolo: cerca de 6% da largura do logotipo, nos quatro lados. Mínimo de 160 px na tela e 40 mm no impresso.

Arquivo ou data URI

Com a pasta assets/ ao lado do HTML, use o arquivo (blocos 01 a 03). HTML que viaja sozinho leva a marca embutida em data URI (blocos 04 a 06).

Respiro e tamanho mínimo

O respiro que se calcula sozinho.

Uma classe põe a área de proteção em volta da marca e trava o tamanho mínimo. Mude só a largura.

xx

Faixa tracejada: a área de proteção, com x de cada lado. Linha fina: o limite do arquivo. Horizontal com 280 px, vertical no mínimo de 120 px, símbolo com 48 px.

Valores medidos no vetor e arredondados para cima. Avatar e favicon já trazem a margem dentro do círculo.

CSS
/* Instituto ISC · respiro e tamanho mínimo da marca (Fio de Ouro v1).
   x = 2 × o diâmetro de um ponto do símbolo.
   Horizontal: x = 6% da largura L. Vertical: 9%. Símbolo isolado: 17%.
   O padding é o respiro: nada entra nele (texto, borda, outra marca).
   Mude só a largura (--l); a altura acompanha.

   Tamanho mínimo
   Horizontal ... 160 px na tela · 40 mm no impresso
   Vertical ..... 120 px na tela · impresso a definir com o designer
   Símbolo ...... 24 px na tela · 8 mm no impresso
   Abaixo do mínimo da horizontal, use o símbolo isolado. */
.marca-respiro{
  --l:280px;       /* largura do logotipo */
  --min:160px;     /* mínimo na tela */
  --x:.06;         /* respiro: 6% da largura */
  display:inline-block; box-sizing:border-box;
  max-width:100%; vertical-align:top;
  padding:calc(max(var(--l), var(--min)) * var(--x));
}
.marca-respiro > img{
  display:block; height:auto;
  width:var(--l); min-width:var(--min); max-width:100%;
}
.marca-respiro--vertical{ --min:120px; --x:.09; }
.marca-respiro--simbolo{ --min:24px; --x:.17; }
@media print{
  .marca-respiro{ --min:40mm; }
  .marca-respiro--vertical{ --min:120px; }  /* impresso: a definir */
  .marca-respiro--simbolo{ --min:8mm; }
}
